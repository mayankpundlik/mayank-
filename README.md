# Weather Tracker

## Project Title and Brief Description

**Weather Tracker** is a mini project web application that allows users to search for the current weather of any city. The project was built using Codex and focuses on frontend development, API integration, responsive design, and user-friendly error handling.

The user enters a city name, and the application fetches live weather information such as temperature, humidity, wind speed, wind direction, and weather condition. The project is lightweight, simple to use, and suitable for academic demonstration.

## Technology Stack and Tools Used

- **HTML5**: Used to create the structure of the web page.
- **CSS3**: Used for styling, layout, responsive design, colors, and visual presentation.
- **JavaScript**: Used for input validation, API calls, data processing, and dynamic UI updates.
- **Open-Meteo API**: Used to fetch real-time weather and geocoding data.
- **Browser Local Storage**: Used to store recent city searches.
- **Codex**: Used for project development, documentation, and improvement.
- **GitHub**: Used for uploading and sharing the project repository.

## Features and Functionalities Implemented

- Search weather by entering a city name.
- Fetch real-time weather data using an external weather API.
- Display current temperature in Celsius.
- Display humidity percentage.
- Display wind speed and wind direction.
- Show current weather condition.
- Validate empty city input.
- Show user-friendly error message for invalid city names.
- Handle API or network failure without crashing the page.
- Store and display recent searches.
- Responsive design for desktop and mobile screens.
- Clean and simple user interface.

## Installation/Execution Steps to Run the Project

1. Download or clone the project repository.

```bash
git clone <your-repository-link>
```

2. Open the project folder.

```bash
cd weather-tracker
```

3. Make sure the following files are present:

- `index.html`
- `styles.css`
- `app.js`

4. Open `index.html` in any modern web browser such as Chrome, Edge, or Firefox.

5. Enter a city name in the search box and click the **Search** button.

6. The application will display the current weather details for the searched city.

## Note

An active internet connection is required because the project fetches live weather data from the weather API.
